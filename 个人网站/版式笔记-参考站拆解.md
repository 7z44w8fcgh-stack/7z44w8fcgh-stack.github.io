# 版式笔记 · 参考站拆解

来源：你提供的截图（1080 px 宽）
原则：**只拆版式、留白、配色、字级**。原站的文字、图片、Logo、签名一律不引用、不复制，本文只描述结构，不转录文案。

> 说明：色号为从截图目测（截图有压缩），不是原站 CSS 值，误差一般在 ±3；用法比数值更重要。

---

## 0 · 一句话结论

它看起来"高级"，不是因为装饰，而是因为**几乎什么都没做**：

- **严格左轴**——每一块都从同一条竖线起排，从不居中
- **字号差 4 倍**——大标题和正文之间是断崖，不是渐变
- **零装饰**——没有卡片、没有圆角、没有阴影、没有分隔线、没有按钮描边

（对照一下：我们现在这版有 6px 圆角按钮、1px 分隔线、暖纸底——都是"装饰"，它们正是这种风格要删掉的东西。）

## 1 · 页面从上到下分成哪几块

| # | 区块 | 位置与占比 | 起什么作用 |
|---|---|---|---|
| ① | **身份条** | 顶部一行，高约 1.5%。左侧 3 枚纯黑小标签；右侧一枚圆形头像（直径约 12%，内含叠字签名） | 三十秒内回答"这是谁、怎么联系、去哪儿找我"。标签是出口，头像是签章 |
| ② | **宣言区** | 高约 20%。左侧 33% 是大标题（3 行）；右侧并排 3 栏小字，每栏宽约 8%，行宽只有 20–28 个字 | 用一句话定调，再用极小的字补细节。"喊"和"说"同时出现，形成反差 |
| ③ | **主作品图** | 高约 50%。左侧 60% 通宽大图，白底产品照，**与页面背景无缝**，看不出图的边界 | 用"图本身就是页面"来去容器化，视觉上不出现一个"卡片" |
| ④ | **次级图 + 条目说明** | 右侧 30%。一张 16:9 视频缩略图，其下是「编号（极小）+ 作品名（中号 2 行）+ 右侧一栏小字」 | 建立**作品索引系统**：06 之后还会有 07、08…… 暗示"还有很多"，无需罗列 |
| ⑤ | （循环） | 截图未展开 | 同样的 ③④ 结构重复，靠编号递进，不加任何过渡元素 |

**关键洞察：** 它的信息层级只有两级——**大字**和**小字**。没有"中号"，没有第三种颜色，没有图标系统。层级靠位置和字号，不靠颜色。

## 2 · 网格与留白

| 项 | 数值（按 1080 截图目测） | 换算到 1440 宽 |
|---|---|---|
| 页面左/右边距 | 约 16 px（1.5%） | 约 21 px |
| 版面 | 12 栏，栏距约 20 px，**贴边不居中** | 同 |
| 大标题宽度 | 约 360 px（33%） | 约 480 px |
| 小字栏宽 | 约 80–100 px（8%） | 约 110–130 px |
| 小字行宽 | 20–28 个字符 | 同 |
| 区块纵向间距 | 100 px 以上 | 约 135 px |
| 主图占地 | 60% 宽 × 50% 高 | 同 |

**判断：整体「疏朗」，不是紧凑。** 但它疏朗的方式很特别——横向边距极小（贴边），纵向留白极大。也就是说：**它把"紧"用在左右，把"松"用在上下**。这跟常见的居中容器（四周都留白）完全相反，所以看起来像杂志跨页，而不是网页。

## 3 · 配色

| 用途 | 色号 | 说明 |
|---|---|---|
| 页面背景 | `#FFFFFF` | 纯白，不是米白 |
| 主文字 / 大标题 | `#0B0B0B` | 近黑，不是纯黑；大面积文字用纯黑会"扎" |
| 标签底色 | `#000000` | 纯黑小色块 |
| 标签文字 | `#FFFFFF` | 纯白 |
| 次级信息 | 同 `#0B0B0B` | **没有灰阶层**，靠 8–10 px 的小字号压低存在感 |
| 图像暖色 | `#A9713C` — `#C68A4E` | 来自照片里的暖光，**不是 UI 色** |
| 边框 / 阴影 / 分隔线 | 无 | 全站不出现 |

**用色原则：** 整页只有一个"颜色事件"——照片里那一块暖光。因为其余部分全是黑白，这抹暖色才成立。**这是它最值得学的一手：与其给 UI 配色，不如给内容留一个色。**

## 4 · 字体的感觉

**类型：** 新怪诞无衬线（neo-grotesque）——Helvetica Now / Neue Haas Grotesk / Suisse / Inter 这一路。
字腔偏小、端点平切、笔画粗细几乎均匀。

**感觉：理性、中性、偏冷。** 既不粗犷，也不优雅；是"工程感的干净"。它不讨好你，但很可信。

**大小对比：极强。**

| 层级 | 截图字号 | 与正文之比 | 粗细 | 行距 |
|---|---|---|---|---|
| 大标题 | 约 44 px | **4 : 1** | 500（medium，不是 700） | 1.05（很紧） |
| 作品名 | 约 24 px | 2.2 : 1 | 500 | 1.15 |
| 正文 | 约 10–11 px | 1 : 1 | 400 | 1.5 |
| 标签 | 约 8–9 px | 0.8 : 1 | 500 | 1 |

注意两点：**标题不靠加粗，靠放大**；**正文小到反常**（10 px 在中文里根本不能用）。它敢用小字，是因为英文单词短、字距紧，中文照搬会糊。

**中文字体对应建议：** 思源黑体 Medium / 苹方 中黑。**不要用宋体**——宋体是优雅一路，会把这种"工程感"换成"书卷气"，气质全变。

## 5 · 排版风格

| 维度 | 它的做法 |
|---|---|
| 对齐 | **严格靠左**。全页没有一处居中文本（唯一的圆是头像） |
| 留白 | 横向极窄（16 px）、纵向极宽（100 px+），靠"少"制造呼吸 |
| 密度 | 低。一屏只有 1 个大标题 + 3 栏小字 + 1 张图 |
| 容器 | **无卡片化**。图片直接铺在页面上，没有框、没有padding、没有圆角 |
| 层级手法 | 字号 + 位置，**不用颜色、不用图标、不用加粗** |
| 分隔 | 没有一条分隔线。区块之间靠留白隔开 |
| 动效 | 截图看不出；这种风格通常只做轻微淡入，不做位移 |

## 6 · 哪些能学，哪些别学

| 能学（且适合我们的） | 别学（会伤到我们） |
|---|---|
| ✅ 严格左轴，所有块对齐同一条线 | ❌ 10 px 小字——中文最小 14 px，否则手机上无法读 |
| ✅ 字号断层：标题和正文拉到 3–4 倍 | ❌ 全黑白——心理行业用纯黑白太冷，我们的暖纸底是对的 |
| ✅ 用极小字补细节，大字只喊一句 | ❌ 16 px 贴边——手机需要 20–24 px 边距，否则手指压字 |
| ✅ 去卡片、去阴影、去多余圆角 | ❌ 大图白底无缝——我们没有产品图，硬凑会显空 |
| ✅ 编号索引（06、07…）建立"还有更多"的暗示 | ❌ 12 栏贴边网格——手机上做不了，只能降成单栏 |
| ✅ 只用一种字体家族，靠字号分层级 | ❌ 头像里叠手写签名——那是品牌资产，我们没有 |

## 7 · 搬到手机上怎么改（375 px）

| 桌面做法 | 375 px 改法 |
|---|---|
| 大标题 44 px、占 33% 宽 | `clamp(28px, 8vw, 40px)`，占满整宽，最多 3 行 |
| 3 栏小字并排 | 折成 1 栏，每段限制 2–3 行，段间距 16 px |
| 12 栏贴边网格 | 单栏 + 24 px 边距；只保留"左轴"这一个特征 |
| 头像 12% 直径 | 88–96 px，放在标题上方或标题右下（不要和标题抢） |
| 编号 06 在标题左侧 | 编号移到标题**上方**一行，小字，单独占一行 |
| 大图 60% 宽通栏 | 满宽出血（左右 0 边距），高度按 4:3 或 1:1 裁 |

**一句话：把它的"左轴 + 字号断层 + 零装饰"搬过去，把"多栏 + 贴边 + 10 px"留在桌面。**

## 8 · 与我们现在这版（v0.3）的差异

| 项 | 我们现在的 | 参考站的 | 建议 |
|---|---|---|---|
| 底色 | 暖纸 `#F7F4EE` | 纯白 `#FFFFFF` | **保留暖纸**。白底 + 黑白字是我们的"冷版"，会丢掉人味 |
| 主色 | 墨绿 `#2E4A3E`（按钮） | 无主色，黑即主色 | 按钮可以保留墨绿，但**改成直角**，圆角收到 0 或 2 px |
| 分隔线 | 1 px 细线分区块 | 一条都没有 | 删到只剩 1–2 条（页脚上方那条留着，其余用留白隔） |
| 字号对比 | 标题 27–40 / 正文 17 ≈ 1.9 : 1 | 4 : 1 | **拉到 3 倍以上**：标题做大，正文不动 |
| 事实条 | 三栏居中数字块 | 无此结构，数字做成极小索引 | 保留（对同行有用），但去掉三栏居中感，改成左对齐 |
| 编号系统 | 无 | 有（06、07…） | 可借用：三个动作前已经有 01/02/03，把编号做得更小更轻 |
| 留白 | 区块间距 72 px | 100 px+ | 拉到 96–112 px |

**如果只动三处，我建议：** ①圆角收平 ②分隔线删剩两条 ③标题再放大一档。这三处一动，气质立刻靠近它，但不必变成它。
