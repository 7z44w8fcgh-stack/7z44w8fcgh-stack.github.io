# 预览与发布说明

不用装任何开发环境。全程只用两样东西：**浏览器** 和 **GitHub 网页**。

---

## 0 · 文件在哪

```
个人网站/
└── site/                ← 要发布的就是这个文件夹里的东西
    ├── index.html       页面本体
    ├── styles.css       样式
    ├── script.js        两个小功能（底部浮条、复制微信号）
    └── assets/
        └── portrait.jpg 你的照片（26 KB）
```

总大小约 40 KB，没有任何外部依赖（不加载网络字体、不用框架、无统计代码）。

## 1 · 电脑上预览

### 方法 A：最快（10 秒）

打开「访达」→ 进入 `site` 文件夹 → **双击 `index.html`**，浏览器就打开了。

> 缺点：双击打开时地址是 `file://...`，微信「复制」按钮可能被浏览器拦。其他都正常。

### 方法 B：要测复制按钮（推荐）

打开「终端」，复制粘贴这两行、回车：

```bash
cd ~/Documents/工作/壹心理/AI/个人网站/site
python3 -m http.server 8000
```

然后浏览器打开 **http://localhost:8000**

- Mac 自带 python3，不需要安装任何东西
- 关掉服务：回到终端按 `Control + C`
- 想改端口就把 8000 换成别的数字

## 2 · 手机上预览

**情况一：还没发布**

1. 先按上面「方法 B」把本地服务开起来
2. 手机和 Mac 连**同一个 Wi-Fi**

4. 手机浏览器打开 `http://192.168.1.23:8000`

**情况二：已发布**（更真实，能看到真实网速和微信里的打开效果）

直接用手机打开你的 GitHub Pages 网址。发给朋友看时，也是这个网址。

## 3 · 发布到 GitHub Pages（5 步，约 3 分钟）

**第 1 步** 登录 github.com → 右上角 `+` → **New repository**
- Repository name 随便起，建议 `about`（网址会短一点）
- 选 **Public**
- 下面的 "Add a README file" 等勾选项**都不要勾**
- 点 **Create repository**

**第 2 步** 进入仓库 → 点 **Add file** → **Upload files**
- 打开 `site` 文件夹，把**里面的四样东西**拖进网页：
  `index.html`、`styles.css`、`script.js`、`assets` 文件夹
- ⚠️ 拖的是这四样，**不是把 `site` 文件夹整个拖进去**（否则网址会多一层 `/site/`）

**第 3 步** 页面下方点 **Commit changes**

**第 4 步** 点仓库上方 **Settings** → 左侧栏 **Pages**
- Source 选 **Deploy from a branch**
- Branch 选 **main**，目录选 **/ (root)**
- 点 **Save**

**第 5 步** 等 **1–2 分钟**，刷新这个 Settings → Pages 页面，顶部会出现一行：
> Your site is live at `https://你的用户名.github.io/about/`

这个网址就是你的网站。手机打开，发给朋友也用它。

**以后改内容**：Add file → Upload files 覆盖同名文件 → Commit，约 1 分钟自动更新。

## 5 · 容易踩的四个坑

1. **文件名大小写**：GitHub Pages 区分大小写，照片必须叫 `portrait.jpg`（全小写），写成 `Portrait.JPG` 会裂图。
2. **上传层级**：上面第 2 步拖错了，网址会变成 `…/about/site/`，能打开但很别扭。拖错了就删掉重新传。
3. **别急着刷**：第一次生效要 1–2 分钟，期间打开可能是 404，正常。
4. **改完不生效**：多半是浏览器缓存，手机下拉刷新，或换个浏览器试。

## 6 · 这次交付的移动端实测记录

| 测试宽度 | 结果 |
|---|---|
| 375 × 812（iPhone 常见） | 无横向滚动，`scrollWidth` = 375，页面总高 2337 |
| 320 × 568（小屏） | 无横向滚动，标题断行已修正 |
| 1280 × 900（桌面） | 版心 680，居中，浮条按钮收进 592 |

**发现并修掉的真问题（4 个）：**

1. **文字贴边**：区块内写了 `padding: 76px 0 0`，把容器的左右 24px 留白覆盖掉了，导致标题、照片、按钮全部顶到屏幕边缘。改成只写 `padding-top` / `padding-bottom`，左右留白交还给容器。
2. **标题溢出**：首屏大标题在 375 宽下超出约 40px，在 320 宽下把「特点，」挤成孤字成行。改为 `clamp(23px, 7.4vw, 40px)`，两档都成立。
3. **底部浮条不出现**：原用 IntersectionObserver 监听首屏，在无头浏览器里回调不触发（真机可能正常，但不值得赌）。改成 scroll 事件直接算位置，少一层异步，行为可预测。
4. **桌面浮条拉满全宽**：1280 宽时那颗绿色按钮横贯全屏，很凶。给它加了 592px 上限并居中。

**已验证的交互：**

- 滑过首屏 → 底部浮条出现（`class="on"` 切换正常）
- 点「复制」→ 提示浮出（`已复制` / 失败时提示长按复制）
- 照片正常加载（`naturalWidth > 0`），无 404
